# Lineage 2 skills SP

Live: https://l2-skills.vercel.app

SP calculator for Lineage II chronicles C1 – High Five. Pick a class, a character level range and the skills you want; the app sums the SP you need.

Skill data and icons are stored in `public/`, so the app makes no external requests at runtime.

## Run

```
npm install
npm run dev
```

`npm run build` writes the static site to `dist/`.

## Languages

The interface is in Polish and English (i18next, react-i18next). Texts are in `src/i18n/pl.json` and `src/i18n/en.json`; a key missing from either file fails the type check. The first visit follows the browser language (English when it is neither), and the choice made in the header is kept in localStorage. Skill descriptions and effects are English game data; `public/data/i18n/pl.json` translates them sentence by sentence with numbers replaced by `#`, and a sentence missing there is shown in English. Skill, class and item names stay in English.

## Data

`public/data/*.json`, `public/data/monsters/*.json`, `public/data/books/*.json`, `public/data/spawns/*.json` (one file per chronicle), `public/maps/` and `public/icons/` are generated by a local scraper that is not part of this repository.

Every spellbook, amulet and other item a skill needs has its game icon (`public/icons/items/`) and a page (`#/<chronicle>/book/<id>`) with the skills it teaches, the merchants that sell it (town and price with the town tax), the monsters that drop it with the drop chance, and quests that give it as a reward (every quest of the chronicle is checked). A world map shows where the dropping monsters spawn; clicking a monster zooms to its spawn areas. Spawn areas come from `public/data/spawns/*.json` and the maps from `public/maps/`, both drawn the way lineage2wiki.org draws them. Shops and drops are the server data that lineage2wiki.org shows for each chronicle.
